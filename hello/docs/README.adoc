== Adding screen evidence

Screens are documented once per screen state, not once per test case. Each test case refers to
figure IDs (for example FIG-S15-01) from the evidence catalogue.

. Take the screenshot or photo listed for the figure in the test report (section Evidence).
. Save it as `test_report/evidence/<FIG-ID>.png`.
. In the test report, replace the placeholder block of that figure with the `image::` line that
  the placeholder shows.

== Updating results

Update the Result column in the test report's "Results by Area" tables, then update the
Executive Summary counts. Every FAIL needs a Jira ORPT defect in the Defect Register.

== Related test tools

Test scripts and host tests are in `CM7/test/`:

* `host_canlog/` - host unit test of the CAN logger (`bash run_host_test.sh`)
* `can_conformance/` - automated CANopen conformance checks over the SLCAN bridge
* `m1_bench_sim/` - bench simulator of the main controller (Node 0x04)
* `sd_canlog/check_canlog.py` - SD card log integrity checker
* `nmt_test/`, `rpdo_test/`, `sdo_test/`, `tpdo_test/` - single-purpose protocol scripts
